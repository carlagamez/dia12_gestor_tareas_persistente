## 🚀 Proyecto: Gestor de tareas persistente

El programa permite:

- Añadir nuevas tareas
- Guardarlas en un archivo `tareas.txt`
- Leer tareas guardadas previamente
- Mostrar todas las tareas numeradas
- Mantener los datos entre ejecuciones

Esto hace que el programa funcione como una aplicación real.
